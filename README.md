## Overview

Colony Manager adds intelligent work-order automation: set target stockpile thresholds and the mod queues logging, hunting, and farming jobs automatically to maintain them, freeing you from micromanagement.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Colony Manager** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Forestry Manager** | Auto-queues logging and replanting to hit a target tree count |
| **Hunting Manager** | Schedules hunts by species priority to maintain a meat reserve |
| **Farming Manager** | Adjusts sowing and harvest orders based on food target levels |
| **Work Priority Sync** | Integrates with colonist work priorities to respect time budgets |
